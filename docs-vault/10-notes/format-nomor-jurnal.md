# Format Nomor Jurnal

Format: **`JE-YYYYMM-NNNN`**

Contoh: `JE-202608-0001` (jurnal pertama bulan Agustus 2026).

Berbeda dengan [[format-nomor-dokumen]] yang me-reset penomoran per tahun per jenis dokumen.
